RNA-seq R analysis script
=========================
Copy RNAseq_analysis.R into your existing RNAseq_Project/DEG folder.
Keep counts.csv and metadata2.csv there too. In RStudio, set the working
directory to DEG, then source the script after installing dependencies.

This is a cleaned reconstruction of your course-practical commands, not a
byte-for-byte export of your R session. It has not been run against your
local input files, so check the results before publishing.

The separate gapminder/ggplot practice was intentionally excluded.
